boopackage
==========

``boopackage`` is a deliberately small package used by the
`Python Package Example <https://github.com/gusreyes01/python-package-example>`_
repository. It demonstrates absolute and relative imports while keeping the
runtime behavior easy to inspect.

Usage
-----

.. code-block:: python

   from boopackage.boomodule import boofunc

   boofunc()

This package is educational and has no runtime dependencies.
